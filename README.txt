運動記録 β v0.12

主な変更
- 「今日のおすすめ」は従来どおり過去履歴を基に表示
- 「新しく試す候補」を追加
  - 過去に記録がない種目のみ対象
  - 最近28日で少なめの部位を優先
  - 新規候補ではマシン・自重をやや優先
  - 初回重量は自動提案しない
  - 候補を開いただけでは記録・履歴に保存しない
- 既存localStorageキー・履歴データ形式は変更なし
- Appleショートカット経由のヘルスケア連携を追加
  - 今日の記録は「保存して連携」から起動
  - 履歴の各記録から過去分も起動可能
  - 送信値は日付・推定アクティブ消費kcal・運動時間
  - PWAからHealthKitへ直接書き込まず、ショートカット「ジムをヘルスケアに記録」を使用
  - 連携開始履歴は gym_log_health_exports_v1 に保存（本体履歴形式は変更なし）
- Service Worker cache version: gym-log-v0.12
